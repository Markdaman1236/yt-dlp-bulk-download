YouTube Search + Bulk Download



Search YouTube by keyword/category, pick videos from a list, and download them with \[yt-dlp](https://github.com/yt-dlp/yt-dlp).



\## Requirements



\- Python 3.10+

\- \[ffmpeg](https://ffmpeg.org/) (needed for merging video+audio and for MP3)

\-yt-dlp >=2024.1.0



\## Install



\### 1. Clone the repo



git clone https://github.com/Markdaman1236/yt-dlp-bulk-download.git

cd yt-search-download



\### 2. Install requirements



pip install -r requirements.txt



\### 3. Install ffmpeg



(Windows) Install ffmpeg from https://www.gyan.dev/ffmpeg/builds/

(Windows) Add to PATH using environment variables and select PATH.



(Linux Debian) sudo apt update

(Linux Debian) sudo apt install ffmpeg



(Linux Fedora) sudo dnf install ffmpeg
